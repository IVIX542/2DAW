# 📚 2DAW - Desarrollo de Aplicaciones Web

¡Bienvenido/a al repositorio central de mi formación en **2º de Desarrollo de Aplicaciones Web (2DAW)**! Este espacio organiza la teoría, ejercicios prácticos, proyectos y entregas del curso académico.

---

## 🗂️ Estructura del Repositorio

El repositorio está organizado por asignaturas y carpetas de recursos para mantener un flujo de trabajo limpio y escalable:

```text
2DAW/
├── Cliente/                      # Desarrollo Web en Entorno Cliente (JavaScript, DOM, etc.)
│   ├── _Recursos_y_Teoria/       # Apuntes, guías y PDFs teóricos
│   ├── _Entregas/                # Prácticas y entregables evaluables
│   ├── ejercicios/               # Colecciones de prácticas y ejercicios modulares
│   └── unidades_teoria/          # Contenido desglosado por unidades
│
├── Despliegue/                   # Despliegue de Aplicaciones Web (Git, GitHub, Servidores)
│   ├── _Documentacion/           # Guías oficiales y apuntes del tema
│   └── proyectos/                # Proyectos prácticos y actividades integradas
│
├── Express_js/                   # Servidores y APIs REST con Node.js y Express
│
├── Interfaces/                   # Desarrollo de Interfaces Web (HTML5, CSS3, UX/UI)
│   ├── _Documentacion/           # Guías de estilo y recursos gráficos
│   └── practicas/                # Prácticas guiadas de maquetación y posicionamiento
│
├── Ingles/                       # Inglés técnico aplicado al ámbito profesional
│
└── _General/                     # Horarios, accesos directos y recursos transversales
```

---

## 🛠️ Tecnologías y Herramientas Principales

* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Backend:** Node.js, Express.js.
* **Control de Versiones:** Git y GitHub.
* **Entornos de Desarrollo:** Visual Studio Code.

---

## 🚀 Puesta en Marcha / Scripts Útiles

Este repositorio incluye un script de automatización (`organizar_2daw.sh`) para mantener la estructura limpia y ordenada de forma rápida.

Para ejecutarlo localmente:
```bash
chmod +x organizar_2daw.sh
./organizar_2daw.sh
```
