Ejercicios de Práctica de JavaScript

Bloque 1: Asignaciones y Operadores Avanzados

(Basado en Asignaciones, Operadores, Comentarios y Sentencias.pdf)

  1. Operadores de asignación lógica (||= y ??=): Declara una variable configuracion con valor null y otra variable llamada modoOscuro con valor false.

    • Utiliza el operador de asignación lógica ??= para que, si configuracion es null o undefined, tome por defecto el objeto { tema: "claro" }.
    • Utiliza el operador de asignación lógica ||= en modoOscuro asignándole true. Explica mentalmente por qué modoOscuro cambia (o no cambia) basándote en los conceptos de valores falsy y truthy.
    • Muestra ambos resultados por la consola con console.log.

  2. Desestructuración avanzada de objetos: Dado el siguiente objeto:

    let empleado = { id: 104, datosPersonales: { nombre: "Sofía", puesto: "Diseñadora" } };

    Utiliza la desestructuración para extraer la propiedad nombre renombrándola como nombreEmpleado y la propiedad puesto. Muestra ambas variables por consola.

Bloque 2: Condicionales Múltiples y Operador Ternario

(Basado en Condicionales en JavaScript.pdf)

  1. Cálculo de tarifa de transporte con condicionales anidados: Escribe un programa que pida al usuario su edad mediante prompt y la convierta a número con Number(). Utiliza una estructura if...else if...else para determinar el precio de un billete de autobús según las siguientes reglas:

    • Menores de 6 años: entrada gratuita (0 €).
    • Entre 6 y 17 años (ambos incluidos): tarifa infantil (5 €).
    • Entre 18 y 64 años: tarifa general (10 €).
    • 65 años o más: tarifa reducida para mayores (6 €).

    Muestra el resultado utilizando alert.

  2. Validación rápida con operador ternario: Crea una variable numérica llamada stock. Utiliza el operador ternario (?:) para asignar a una variable mensaje el valor "Disponible" si el stock es mayor que 0, o "Agotado" si es igual o menor a 0. Muestra el mensaje resultante en la consola.

Bloque 3: Bucles y Control de Flujo

(Basado en Bucles en JavaScript.pdf)

  1. Recorrido inverso con bucle while: Utiliza un bucle while para crear una cuenta atrás numérica que empiece en el número 15 y termine exactamente en el 5 (ambos incluidos), mostrando cada número por la consola en cada iteración. Asegúrate de actualizar la variable contador correctamente dentro del bucle.

  2. Bucle for...in en objetos: Declara un objeto literal que represente la configuración de una aplicación:

    let configApp = { idioma: "es", modoOscuro: true, version: "2.1" };

    Utiliza un bucle for...in para recorrer sus claves y valores, mostrando en la consola cada clave acompañada de su valor formateado (por ejemplo: idioma: es).

Bloque 4: Funciones Avanzadas

(Basado en Funciones en JS.pdf)

  1. Funciones flecha con un solo parámetro y retorno implícito: Crea una función flecha llamada calcularCubo que reciba un único número como parámetro, omita los paréntesis del parámetro y devuelva directamente el cubo de ese número (n ** 3) utilizando el retorno implícito (sin usar las llaves {} ni la palabra return). Pruébala pasando el número 3 y muestra el resultado en la consola.

  2. Uso de funciones predefinidas globales y de Math: Escribe un pequeño programa que reciba una cadena de texto numérica introducida mediante un prompt (por ejemplo, "25.75"). Utiliza la función predefinida parseFloat() para convertirla a número decimal y, a continuación, aplica el método Math.floor() para redondearla siempre hacia abajo. Muestra el resultado final por consola.

Bloque 5: Colecciones Avanzadas: Arrays, Set y Map

(Basado en Colecciones en Javascript.pdf)

  1. Filtrado y transformación combinada en Arrays: Dado el siguiente array de precios:

    let precios = [12, 45, 8, 30, 99, 15];
    • Utiliza el método .filter() para quedarte únicamente con los precios que sean menores o iguales a 30.
    • A continuación, sobre el array filtrado, encadena el método .map() para aplicar un incremento de 10 a cada precio.
    • Muestra el array final resultante en la consola.

  2. Operaciones de conjuntos con Set (Diferencia): Dados dos arrays de identificadores de usuarios conectados en dos salas distintas:

    let salaA = [101, 102, 103, 104];
let salaB = [103, 104, 105];

    Convierte ambos arrays en objetos Set y calcula mediante el operador spread (...) y el método .filter() los usuarios que están exclusivamente en la salaA pero no en la salaB. Muestra el array u objeto Set resultante por consola.

Bloque 6: Objetos y Programación Orientada a Clases

(Basado en Objetos y clases.pdf)

  1. Métodos y conversión a JSON: Crea un objeto literal llamado empleadoEmpresa con las propiedades: nombre (string), departamento (string) y un método llamado detalles() que devuelva una cadena combinando sus propiedades utilizando interpolación con comillas invertidas. Después, convierte todo el objeto en una cadena de texto en formato JSON utilizando JSON.stringify() y muéstrala en la consola.

  2. Uso de clases, herencia y super: Crea una clase base llamada Dispositivo con un constructor que reciba marca y un método encender() que muestre por consola "El dispositivo está encendido". A continuación, crea una clase hija llamada Smartphone que extienda (extends) de Dispositivo, añada una nueva propiedad llamada sistemaOperativo en su constructor utilizando super(), y añada un método propio llamado llamar(). Instancia un objeto de la clase hija y prueba a ejecutar sus métodos.
